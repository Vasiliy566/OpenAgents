# OpenAgents

Приложения с интерфейсом для AI-ассистентов, собранные и опубликованные через [AppInside](https://appinagents.ru).

**[Открыть каталог](https://appinagents.ru/market)** · [Как установить](https://appinagents.ru/market/install) · [Создать приложение](https://appinagents.ru/studio)

## Установить каталог

Установка выполняется с компьютера: ChatGPT для компьютера, режимы Work и Codex.

Если Codex CLI ещё не установлен, следуйте [официальной инструкции](https://learn.chatgpt.com/docs/codex/cli). Затем в терминале выполните:

```sh
codex plugin marketplace add Vasiliy566/OpenAgents
```

Перезапустите ChatGPT для компьютера. В Work или Codex откройте каталог плагинов, выберите источник **OpenAgents** и установите нужное приложение. Подтвердите доступ в открывшемся окне AppInside - сервиса, на котором работает приложение. Затем откройте новый чат с плагином. При необходимости войдите также в свой аккаунт исходного сервиса.

Обновить уже добавленный каталог:

```sh
codex plugin marketplace upgrade openagents
```

GitHub-каталоги работают в совместимых клиентах Work/Codex. Доступность интерфейса зависит от клиента. OpenAgents распространяется отдельно от официального каталога ChatGPT и не означает одобрение OpenAI.

[Документация OpenAI по каталогам](https://developers.openai.com/plugins/build/plugins#build-your-own-curated-plugin-list)

## Опубликовать своё приложение

1. Создайте приложение в [AppInside](https://appinagents.ru/studio).
2. Выберите сценарий, настройте карточку и проверьте предпросмотр.
3. В разделе публикации выберите **OpenAgents**, укажите публичное имя издателя и подтвердите условия.
4. AppInside проверит пакет, запишет его в этот репозиторий и добавит карточку в каталог автоматически.

Первые приложения появятся после подтверждения владельцами. Уже созданные проекты автоматически в каталог не добавляются.

## Формат

```text
.agents/plugins/marketplace.json
plugins/<plugin-name>/
  plugin.json
  mcp.json
  README.md
  assets/
```

Используем переносимый формат Agent Plugins: название, версия, описание, издатель, иконка, скриншоты и MCP-подключение. Интерфейс размещён в AppInside. В репозитории нет бизнес-данных, ключей API или исходного кода пользователей.

## Проверка

При публикации и в GitHub Actions проверяются состав файлов, структура манифеста, изображения, известные форматы секретов и подключение к размещённому AppInside MCP через OAuth. Локальные команды, хуки и исполняемые компоненты не допускаются.

Это базовая проверка пакета, а не гарантия безопасности всех действий удалённого сервиса. Подробности: [SECURITY.md](SECURITY.md) и [правила каталога](https://appinagents.ru/market/terms).

Владелец может убрать приложение через раздел публикации в AppInside. Оно исчезнет из текущего каталога; предыдущие коммиты и скачанные копии сохранятся.

## Проверить репозиторий локально

Нужен Node.js 24 или новее, установка зависимостей не требуется:

```sh
node scripts/validate.mjs
```

Материалы приложений принадлежат их правообладателям. Публичное размещение не предоставляет отдельной лицензии на товарные знаки или внешний сервис.
