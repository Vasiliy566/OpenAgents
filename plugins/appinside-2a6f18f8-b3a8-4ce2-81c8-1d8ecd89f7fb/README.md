## Установить

1. Установите [Codex CLI](https://learn.chatgpt.com/docs/codex/cli). Добавьте каталог: `codex plugin marketplace add Vasiliy566/OpenAgents`. Если каталог уже добавлен: `codex plugin marketplace upgrade openagents`.
2. Перезапустите приложение ChatGPT для компьютера. В Work или Codex откройте каталог плагинов, выберите источник OpenAgents и это приложение.
3. Нажмите «Установить» и подтвердите доступ через AppInside - сервис, на котором работает приложение. Если сервис требует отдельного входа, подключите свой аккаунт сервиса.
4. Откройте новый чат и выберите установленный плагин.

Каталоги GitHub поддерживаются в совместимых клиентах Work/Codex. Доступность интерфейса зависит от клиента. Размещение здесь не означает публикацию в официальном каталоге ChatGPT.

## Проверка пакета

Проверены структура, изображения, отсутствие известных форматов секретов и локальных исполняемых компонентов. Пакет подключается к размещённому AppInside MCP через OAuth. Интерфейс работает на сервере, данные и ключи пользователей в репозитории не хранятся. Это базовая проверка пакета, а не гарантия поведения удалённого сервиса.
